Vibershot 0.1.2

New look
- A dark theme across the whole app, with a redesigned launcher.
- A new purple icon and logo.
- Tooltips are readable: dark, in the app's style.

Editor
- New layout: a menu bar with every command, an action rail, and tools as labelled rows with their options underneath.
- Callout tool (O): labels with arrows, speech, oval and thought bubbles.
- Stamp tool (K): 18 searchable stamps such as ticks, crosses, pointers and stars.
- Blur tool (B): blur or pixelate with a brush or a box, or blur a marquee selection. The hidden pixels are really gone from the export.
- New canvas (Ctrl+N), Canvas size and Image size dialogs.
- A number box beside every slider takes values past the slider's range.
- Arrow heads can be rounded.

Elsewhere
- Region capture: a size bar with 720p, 1080p, 1440p, square and custom frames that you place with a click.
- Gallery: drag the dividers to resize the side rail and the detail pane; the widths are remembered.
- Launcher: long status messages wrap instead of being cut off.

Changed shortcuts
- Ctrl+0 now shows the picture at actual size instead of fitting it to the window. Both can be set in Settings > Editor.
- Ctrl+N opens New canvas; New from clipboard is now Ctrl+Shift+N.
